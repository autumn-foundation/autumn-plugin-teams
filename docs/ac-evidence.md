## TDD record

- SPEC first: `verus/policy.rs` written before any Rust code. Verus could
  not be built in the dev container (the sandbox refused to build fetched
  code), so CI runs the proofs.
- RED: 96 tests failed on `todo!()` stubs. 12 structural tests passed (data
  shapes, counters, fakes, route declaration).
- GREEN: all tests passed. Then REFACTOR with fmt and clippy clean.
- Review fixes followed the same loop: 16 new tests failed first, then
  passed after the fix. One test passed for the wrong reason
  (`a_health_timeout_does_not_cancel_the_token_request`); it was made
  time-based, failed, then passed.
- The context helpers test (`context_sends_types_updates_and_deletes_…`) was
  written after the code, to close a coverage gap. It passed at once.
